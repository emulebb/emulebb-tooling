# emulebb-rust Closed Items

This directory is the durable archive for completed and rejected emulebb-rust
backlog records. The [active index](../../active/INDEX.md) lists only open work.

Each item file is authoritative for its decision, implementation evidence, and
closure reason. Do not duplicate the inventory here, and never reuse an ID from
this directory. Use the filename, repository search, or the linked GitHub issue
to locate a closed record.
