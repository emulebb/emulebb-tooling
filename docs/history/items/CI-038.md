# CI-038 - UI Resource-Depth and Language Smoke Gate

## Summary

Add a dedicated live E2E profile for release resource coverage. The profile
loads every canonical stock language DLL from the release output, launches an
isolated profile per language, and exercises the main menu shell, representative
view commands, and Preferences tree. Missing language DLLs and UI/resource
failures are hard failures.

## Acceptance

- [x] `live-e2e --profile ui-resource-depth` is a supported aggregate profile.
- [x] The profile includes `resource-ui-smoke` plus the existing Preferences UI
      roundtrip.
- [x] `resource-ui-smoke` reads the canonical
      `repos\emulebb-tooling\helpers\rc-release-languages.json` manifest.
- [x] Release scope fails when any stock language DLL is missing from the app
      output.
- [x] Each selected language runs in an isolated profile and verifies main
      window startup, top-level menu shell, representative view commands, and
      Preferences tree availability.
- [x] Aggregate reports classify live-network inconclusive children separately
      from blocking harness/app inconclusive states.
- [x] A current-head `ui-resource-depth` live run is recorded before final
      packaging.
